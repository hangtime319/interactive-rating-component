# Interactive Rating Component

A responsive, two-state interactive rating component, styled with Tailwind CSS and powered by JavaScript.

## Description

This project is a solution to the "Interactive rating component" challenge from Frontend Mentor. The main goal was to build a small, functional component with two states: a rating selection state and a "thank you" state that appears after submission. This project is an excellent example of using **Tailwind CSS** for clean, modern styling and **JavaScript** for handling all the user interactions and dynamic state changes.

## Technologies Used

* **HTML5:** For creating the semantic structure of the rating card and its different elements.
* **Tailwind CSS:** Used for all the styling, including the layout, typography, colors, and responsive design. Tailwind's utility classes made it fast to style both the initial and the "thank you" states.
* **JavaScript:** This is the core technology that handles the component's interactivity. It listens for user clicks on the rating numbers, manages the highlighting of the selected rating, handles the "Submit" button click, and dynamically switches the view between the rating and the thank-you states.

## Installation

This is a static frontend project, so no complex setup is required. The Tailwind CSS is already compiled. To get a local copy, simply follow these steps:

1.  Clone the repository:
    ```bash
    git clone [https://github.com/hangtime319/interactive-rating-component.git](https://github.com/hangtime319/interactive-rating-component.git)
    ```
2.  Open the `index.html` file in your preferred web browser to view the project.

## Usage

This project serves as a showcase of a practical, interactive UI component. The user can:
* Select a rating from 1 to 5.
* Click the "Submit" button.
* See the view change to a "thank you" card that displays the selected rating.

## Features

* **Two-State UI:** The component seamlessly transitions between a rating view and a "thank you" view.
* **Interactive Ratings:** Users can click to select a rating, and the chosen number is highlighted.
* **Dynamic Content:** The "thank you" message dynamically displays the rating that the user selected.
* **Fully Responsive:** The card is styled to be fully responsive, looking great on all screen sizes.
